# Mobile-Development-Lab-Activity-4-Dart-Exercises
Name: Jereyme James B. Diaz

Section: BSIT 3.4

Activity 4

Scenario: This Dart Exercises program has demonstrates on how to used object oriented programming principles on Parrot Management System. The programme uses abstraction (Bird abstract class), inheritance (Cockatiel and AfricanGrey parrot types), polymorphism (overriding makeSound() function), encapsulation (private parrot ID) and mixins (PetCare). The program will store multiple objects of type Parrot within a list and display their information, species, skills and unique behaviours a special parrot will have 2 behavior like it can whistle while feeding it.

Used: Visual Studio (Purple)

Enter this command on terminal to run the code: Dart run
